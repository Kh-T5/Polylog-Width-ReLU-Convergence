# Polylog-Width-ReLU-Convergence
This repository contains a numerical verification of the theoretical results presented by Ji and Telgarsky (2019) in "Polylogarithmic width suffices for gradient descent to achieve arbitrarily small test error with shallow ReLU networks"

This experiment aims to validate:
1. **The Margin Assumption**: That random initialization provides a "lucky" feature space where a separator $\bar{U}$ exists in the gradient space $\nabla f_i(W_0)$.
2. **Activation Stability**: That the number of ReLU activation flips is bounded even when the width is small (polylog in n, (1/target_error))
3. **Convergence Dynamics**: That GD on logistic loss minimizes test error effectively in the polylog-width regime.

## Experimental Design: Teacher-Student Setup

To test these claims, we implement a **Teacher-Student** framework:

* **Teacher**: A fixed, shallow ReLU network $f^*$ that defines the ground-truth decision boundary.
* **Student**: A ReLU network of variable width $m$ trained on labels generated by the teacher.
* **Optimization**: Gradient Descent on the logistic (cross-entropy) loss.

### Key Metrics
* **Test Error vs. Width**: Observing the phase transition at $m \approx \log(1/\epsilon)$.
* **Alignment Score**: Measuring the cosine similarity between student weights and the ideal separator $\bar{U}$ defined in Equation (2.1) of the paper.
* **Activation Flip Ratio**: Quantifying the fraction of neurons whose activation patterns change during training.
